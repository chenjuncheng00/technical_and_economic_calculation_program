# 技术经济分析计算程序

一个基于 VB.NET 开发的 COM 组件库，专门用于**综合能源项目**（风电、光伏、蓄电池、燃气轮机、暖通空调、垃圾发电、燃煤机组等）的技术经济分析计算。该程序通过 COM 接口与 Microsoft Excel 深度集成，从 Excel 工作簿中读取输入数据、执行复杂的财务计算，并将结果写回 Excel 生成完整的经济评价报表体系。

## 项目概述

| 属性 | 值 |
|------|-----|
| 项目类型 | VB.NET COM Class Library |
| 目标框架 | .NET Framework 4.5.2 |
| 目标平台 | x64 |
| 开发语言 | VB.NET |
| UI 框架 | Windows Forms |
| 集成方式 | COM Interop (Microsoft.Office.Interop.Excel / Word) |
| 代码规模 | ~36,000 行 VB.NET 代码（不含 Designer 文件） |
| VB 文件数 | 40+ 个 .vb 源文件 |
| Excel 工作表数 | 22 个工作表 |
| 支持投资轮次 | 最多 10 次独立投资 |
| 项目计算年限 | 最长 31 年 |

**核心用途：** 能源项目投资可行性分析、财务评价、敏感性分析、收益率临界点反算，一键生成全套经济评价报表。

## 核心计算模块详解

### 1. 建设期资金运用计算.vb（350行）

**模块名:** `建设期资金运用计算`

计算项目在建设期的资金运用情况，是整个计算流程的第一个核心计算步骤。

#### 函数列表

| 函数名 | 类型 | 参数 | 返回值 | 功能说明 |
|--------|------|------|--------|----------|
| `建设期资金运用计算` | Sub | `ExcelApp As Object, zbj_model As Integer` | 无 | **主入口**。读取估算表数据，调用分项计算，将结果（建设期利息、可抵扣增值税、资本金、建设期贷款）写入Excel "投资计划与资金筹措表" |
| `分项建设期资金运用计算` | Function | `ExcelApp, zbj_model, GSBSJ` | Array（26个分项数组） | 为6种设备（常规、蓄电池、逆变器、暖通、光伏、风电）分别计算建设期资金运用金额，返回各分项的贷款利息、可抵扣增值税、资本金、建设期贷款等 |
| `建设期资金运用计算_main` | Function | `zbj_model, dklx_model, jttz_list, kdkzzs_list, ldzj_list, zbjbl_list, dkje_list, dkll, year_list, month_list` | Array(4) | 核心算法：根据资本金比例、贷款金额、利率等参数，计算资本金、建设期贷款、建设期利息、可抵扣增值税 |
| `建设期贷款利息计算_main` | Function | `jsq_index_list, dkje_list, dkll_list, year_list, jsnx` | Array(4) | 逐年计算建设期贷款利息，处理跨年建设期的利息分摊 |
| `建设期贷款利息计算_开工年份` | Function | `dkje, dkll, month_start, month_end` | Double | 计算开工年份的建设期贷款利息（按月份比例折算） |
| `建设期贷款利息计算_建设年份` | Function | `dkje, dkbx_zr, dkll` | Double | 计算建设年份（非首年非末年）的建设期贷款利息 |

### 3. 折旧摊销计算.vb（1135行）

**模块名:** `折旧摊销计算`

计算固定资产折旧和无形资产摊销，支持**直线法（平均年限法）**和**年数总和法**两种折旧方式，支持10次投资分开或合并计算。

#### 函数列表

| 函数名 | 类型 | 参数 | 返回值 | 功能说明 |

正确密码解锁所有工作表并显示隐藏的投资方现金流量表；错误则递增失败计数器。

## 安全与保护机制

### 1. 自保护

- 屏蔽 `Ctrl+Break` 中断键
- 防止用户中断关键计算过程
- 验证失败时自动保存并关闭Excel

### 2. 会计等式验证

- 资产负债表计算后自动验证：资产 - 负债 - 所有者权益
- 总误差 < 0.5 → 标记"正确"
- 总误差 ≥ 0.5 → 标记"不正确"

## 构建与部署

### 构建要求

- Visual Studio 2015 或更高版本
- .NET Framework 4.5.2 SDK
- Microsoft Office（Excel + Word）已安装
- 64位 Windows 操作系统
- COM Interop 引用: Microsoft.Office.Interop.Excel, Microsoft.Office.Interop.Word

### 构建步骤

1. 打开 `技术经济分析计算程序.sln`
2. 选择构建配置: Debug 或 Release
3. 生成解决方案

### 部署步骤

```cmd
regasm 技术经济分析计算程序.dll /codebase /tlb
```

## 注意事项

1. **计算中断**: 计算过程中 `Ctrl+Break` 已被屏蔽，请勿强制关闭
2. **表格保护**: 计算完成后表格自动锁定，需修改请进入维护模式
3. **投资次数**: 最多支持10次独立投资
4. **计算年限**: 项目计算年限最长支持31年
5. **文件备份**: 建议在运行计算前备份 Excel 文件
6. **操作系统**: 仅支持64位 Windows
7. **Office 版本**: 需要安装完整版 Microsoft Office（非 Office 365 精简版）
